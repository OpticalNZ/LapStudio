# An executable with no version metadata looks anonymous, which counts against it
# with Windows Defender's heuristics and with SmartScreen. This does not make the
# file trusted - only a code-signing certificate does that - but a build with a
# publisher, product name and description is treated less harshly than one with
# none at all.
#
# Passed to PyInstaller with --version-file version_info.txt.
# Keep filevers / prodvers in step with the release number.

    date=(0, 0)
  ),
  kids=[
